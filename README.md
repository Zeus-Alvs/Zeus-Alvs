## 🚀 Projetos em destaque

**[Cosmic Mind](https://github.com/Zeus-Alvs/Cosmic-Mind)** — *Destaque no portal G1*
Plataforma de treino cognitivo com jogo em Unity, API analítica em FastAPI + MongoDB Atlas e relatórios clínicos em PDF, com foco em acessibilidade.

**[FleetSync](https://github.com/Zeus-Alvs/Fleet-Sync)**
Motor de matchmaking logístico em Java (Spring Boot) com fórmula de Haversine e painel de controle geoespacial em React/Mapbox.

**[Relay](https://github.com/Zeus-Alvs/Relay)**
Orquestrador de servidor descentralizado (Tailscale + Rclone) que elimina a necessidade de hospedagem paga, com failover automático entre hosts.

📄 Veja todos os projetos e o case completo de cada um no [meu portfólio](https://zeus-alvs.github.io/Portfolio).
